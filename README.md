# DataForge AI

DataForge AI is an AI-powered enterprise data analyst designed to answer
business questions using structured enterprise data.

## Goal

Convert natural-language business questions into reliable data-driven answers.

Example:

"What were the top 10 suppliers by purchase value in Q3?"

DataForge should eventually:

1. Understand the question
2. Identify the required data
3. Generate SQL
4. Validate the SQL
5. Execute the query
6. Analyze the results
7. Explain the answer
